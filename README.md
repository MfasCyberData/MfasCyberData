### Data Engineering & Analytics Engineering
I work across the path from raw operational data to reliable analytical outputs:

`Sources → ETL / ELT → Data Models → Quality → Analytics → Business Decisions`

- ETL cycle: **~30 min → ~6 min (-80%)**
