### Network Threat Detection · ThreatLens

Academic team project based on a sample of **CSE-CIC-IDS2018**.

The final workflow includes:

- duplicate-aware data preparation
- **64 network-flow features**
- Logistic Regression, Random Forest and HistGradientBoosting comparison
- threshold selection on validation data
- detailed false-positive and attack-family analysis
- Flask demonstration application

The final model detects **91.6% of attacks** on the held-out test set, with **Macro F1 ≈ 0.877**.

`Python` · `pandas` · `scikit-learn` · `Flask`

→ [View case study](https://mfascyberdata.github.io/projects/network-threat-detection.html)
